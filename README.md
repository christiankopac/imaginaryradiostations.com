# Imaginary Radio Staions

- Node [v24.22.1](https://nodejs.org/en/blog/release/v24.22.1)
- Built with [SolidStart](https://docs.solidjs.com/solid-start) v2, deployed to Netlify via `@netlify/vite-plugin`

## Development

```bash
npm install
npm run dev
```

## Building

```bash
npm run build
```
